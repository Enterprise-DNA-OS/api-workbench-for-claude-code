# Selection evidence: Postman

Checked 2026-10-24. Family: api-operations. The registry contains software-testing for TestRail case management, but no API collection and request-operations build. This does not reuse the Microsoft workspace governance or research-evidence families built earlier tonight. The reference quality bar was organisation-design-for-claude-code.

USD 11,400 a year is a modelled 50-paid-user Team bill: 19 x 50 x 12. It is not a customer invoice. The live [Postman pricing page](https://www.postman.com/pricing/) lists Team at $19 per user/month billed annually and now asks Enterprise buyers to contact sales. Do not reuse third-party Enterprise figures. Current customer adoption and invoice evidence were not established by the local customer-record search. No live CRM read was attempted because this charter forbids handling secrets and no verified direct CRM tool was available.
