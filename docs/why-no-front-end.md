# Views show the work; commands change it

The database holds inventory, response evidence, review dates and follow-ups. A coding agent runs the same commands an operator can inspect. Branded HTML documents and dashboards are read-only outputs.

A full API client gives interactive request editing, response browsing, authentication helpers, protocol tools and shared workspace collaboration. Mobile use, live co-editing, offline request editing and drag-and-drop are not supplied by these local reports. The base does not recreate Postman's scripts, mocks or performance tests.

The useful owned workflow is the weekly service review and its underlying records. Enterprise DNA scopes a web view, connectors or more advanced checks when that is part of the agreed version. No screen is required to use the inventory, approved read checks, actions and handover in the free version.
